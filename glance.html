開発中 / Chrome Extension

Glance

時計、Googleカレンダー、Google Tasks、天気を一画面にまとめるChrome拡張機能です。

ブラウザを開いた瞬間にその日に必要な情報を確認できます。

GitHubを見る ↗
種類
Chrome新規タブ拡張
公開状況
開発者モード向けに公開
技術
Manifest V3 / Vanilla JavaScript / Google Calendar API / Google Tasks API / OpenWeatherMap

できること

  • 時計

    デジタルとアナログ、それぞれ5種類のデザインから選べます。

  • 月間カレンダー

    Google Calendarと連携し、予定のある日をマーカーで示します。

  • 日間スケジュール

    その日の予定を時間順のタイムラインで表示します。

  • ToDoリスト

    Google Tasksと連携し、残っているタスクを確認できます。

  • 5日間の天気

    OpenWeatherMapから設定画面で選んだ都市の予報を取得して表示します。

  • 背景の変更

    画像や配色を設定し、新規タブの見た目を調整できます。

  • 推しスケと連携

    推しスケ GAS版でスケジュール画像を解析し、Googleカレンダーへ同期しておけば、Glanceの日間スケジュールにも配信予定が並びます。

現在は開発者モードで導入
